Linked

In this game you can link magical cubes to yourself. When linked these will mirror your movements. It is your mission to use these cubes to find your way to the end.

Linked is a puzzle platformer game made in Unity. I orignally made the prototype for this game in Unreal Engine 4 as a school assignment, but I decided after the assignment was done that Unity would be a better fit for the project.

This project was used as a great opportunity to keep challenging myself and to learn and polish new skilss.
While making this game I expanded my knowledge about Unity, game development, game design, audio,...

Next to the gameplay programming I've also developed several tools in Unity to improve my workflow and make the creation of props and levels easier. An example of this is my modular bookcase system.
