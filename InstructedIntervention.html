Instructed Intervention: A Programming Puzzle Game

Instructed Intervention is a game where you have to solve hostage situations by programming your intervention robot. You can choose from different setups, use the environment to your advantage, and don't forget to avoid making critical errors!

This game is one of my personal projects. My main goal is to make a programming puzzle game that is easy enough for non-programmers to understand and learn, while also challenging those with and without prior programming knowledge.

Some of the features of this game are:

-Grid-based gameplay
-Programming-like system that lets you control your robot’s actions
-Customizable setup for the robot that affects the programming options
-Different programming and setup choices for each level
-Ability to solve multiple solutions for each level
