Palette painter

This a Unity tool that I am currently developping. It is meant to speed up the painting of flat shaded meshes.

With this tool you only need to load in the mesh and start painting, while you are bussy painting the model the unwrap and palette texture gets generated for you.
You can also define multiple colors to a group of polygons, so you can easily switch between colors. This feature can be used to quickly compare possible color combinatations or to generate different palettes for one mesh, by example soldiers with different colored outfits.
When you are done you just save the mesh and texture and it is ready to be used in game.

With this project I have learned more about editor tools in Unity, mainly the editor layout aspect of it.
