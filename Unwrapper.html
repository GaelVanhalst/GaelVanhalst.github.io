Unwrapper

This a tool I made as a school assignment in 2014. It was made in c# using the .net framework and wpf

The idea behind this unwrapper is that it can be used after a texture was already made for the existing unwrap. When altering the unwrap you can load a texture that will be reformed to fit the new unwrap.

This unwrapper can translate, rotate, scale, mirror, break and weld vertices, save and load (models and textures), render the new texture, and more.
